# Portfolio Development Rules

## Tech Stack
- Framework: React with React Router (Hashrouter)
- Styling: Tailwind CSS
- Deployment target: GitHub Pages

## Agent Behavior
- **Never treat code as a black box:** Always output clean semantic HTML and highly accessible (ARIA) components.
- **Check-off Flow:** Every time a structural component is finished, update `tasks.md` to track progress.
- **Continuous Commits:** Draft an artifact for approval before executing a terminal command to commit changes.
- Do the BARE MINIMUM changes. Don't do anything more.
